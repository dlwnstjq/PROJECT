# PROJECT

본 게임은 벽돌깨기 게임에 리듬 게임을 결합한 하이브리드 웹 게임입니다. 

## 주요 기능 및 시스템

* **키보드 기반 조작**: 마우스 없이 좌/우 방향키를 통해 더욱 향상된 조작감을 제공합니다.
* **라이프 시스템**: 
    * **패널티**: 공을 놓칠 경우(MISS) 체력이 감소합니다.
    * **회복**: 콤보 유지 및 'PERFECT' 판정 시 체력이 회복되어 게임 지속 시간을 늘릴 수 있습니다.
* **인터랙티브 노트**:
    * **Long Note**: 발사 키를 누른 상태로 타이밍을 유지해야 하는 롱 노트.
    * **Stream Note**: 공을 N회 발사해야하는 연타 모드.
* **시각적 가이드**:
    * **줄어드는 가이드**: 공이 패들에 근접할수록 판정 범위를 나타내는 가이드라인이 점진적으로 줄어들어, 시각적인 긴장감과 정확한 타격 타이밍을 제공합니다.

## 조작 방법

| 조작 | 기능 |
| :--- | :--- |
| **좌 / 우 방향키** | 패들 이동 |
| **위 방향키** | 공 발사 및 리듬 타격 |
| **위 방향키(꾹 누르기)** | 롱 노트 타격 유지 |
